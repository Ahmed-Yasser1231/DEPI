# DEPI
Software Development program specializing in React Frontend Web Development.

## 📌 Overview
This repository documents my 6-month Software Development training
with a focus on React Frontend Web Development.
It contains course materials, hands-on exercises, mini-projects,
and a final capstone project.

## 🧠 Topics Covered
- HTML5 & CSS
- UX/UI Principles
- JavaScript & TypeScript
- Bootstrap
- React
- Git & GitHub
- Node.js & Express (Backend Fundamentals)
- Docker & Kubernetes (Basics)
- Unit Testing & Functional Documentation
- Prompt Engineering

## 🛠 Tools & Technologies
- React
- Node.js
- Git & GitHub
- Docker
- Kubernetes
- VS Code

## 📂 Repository Structure
Each branch represents a course module or training phase, including
assignments, practice tasks, and projects.

## 🚀 Capstone Project
The training concludes with a real-world web application built using
React for the frontend and Node.js for the backend, applying best
practices, testing, and documentation.
